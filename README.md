# RIITHIS Portfolio

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open [http://localhost:3000](http://localhost:3000).

The public portfolio runs with its included local project data, so a database is not required for local viewing. The optional admin login uses the values already configured in `.env`.

## Production check

Run `npm run build` before deployment, followed by `npm run start` to serve the production build locally.
